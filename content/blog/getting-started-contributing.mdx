# Getting Started with Contributing

Contributing to open source can seem daunting, but we're here to make it easy! This guide will walk you through making your first contribution to TIVerse.

## Prerequisites

Before you start, make sure you have:

- A GitHub account
- Git installed on your machine
- Basic familiarity with your chosen programming language

## Finding a Project

Browse our [projects page](/projects) to find something that interests you. Look for repositories with:

- Active development
- Good documentation
- "good first issue" labels

## Making Your First Contribution

### 1. Fork the Repository

Click the "Fork" button on the repository page to create your own copy.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
cd REPO_NAME
```

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes

Write clean, well-documented code following the project's style guide.

### 5. Commit and Push

```bash
git add .
git commit -m "Description of your changes"
git push origin feature/your-feature-name
```

### 6. Create a Pull Request

Go to your fork on GitHub and click "New Pull Request". Provide a clear description of your changes.

## Best Practices

- Write clear commit messages
- Add tests for new features
- Update documentation
- Be responsive to feedback

## Need Help?

Join our [GitHub Discussions](https://github.com/orgs/tiverse/discussions) to ask questions and connect with other contributors.

Happy contributing! 🎉
